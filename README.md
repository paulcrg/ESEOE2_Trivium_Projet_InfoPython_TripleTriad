# Trivium

Projet réalisé dans le cadre du mini-projet d'informatique de deuxième année à l'ESEO.

## Présentation

Trivium est un bot Discord développé en Python permettant de jouer à **Triple Triad**, un jeu de cartes issu de Final Fantasy VIII.

Le bot permettra de jouer contre un autre utilisateur ou contre une intelligence artificielle.

## Fonctionnalités prévues

- Parties joueur contre joueur
- Parties contre un bot avec plusieurs niveaux de difficulté
- Sauvegarde et reprise des parties
- Commandes Discord pour gérer les parties

## Technologies

- Python 3.12
- discord.py
- SQLite ou MongoDB (à définir)

Les instructions d'installation seront ajoutées au cours du développement.
